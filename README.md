# My First Web Project 🚀

This is my **first complete project**! A few years ago, I started exploring HTML, but due to changes in plans, I put it aside. Now, I’m truly fascinated by web development and fully motivated to create something functional and meaningful.

The goal of this project is to **organize and display information in a clear and practical way**, providing an **intuitive and accessible experience** for **users seeking simplicity and efficiency in their daily tasks**. It’s designed to be a useful, visually appealing, and easy-to-navigate tool.

## Features
- Task list organized by day of the week  
- Add, edit, and delete tasks easily  
- Simple, clean, and user-friendly interface  
- Fully responsive layout
